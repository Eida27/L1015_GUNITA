# Philippines land and administrative geometry, version 1

The vendored `phl-adm2.geojson` is the **unmodified** geoBoundaries gbOpen simplified Philippines ADM2 dataset, ID `PHL-ADM2-2640588`, represented year **2020**, built **2023-07-05**. It contains 87 province-equivalent Polygon/MultiPolygon features in WGS84 longitude/latitude order. Its 3,140,454 bytes have SHA-256 `fa77b9f17db2e419acaae714a935f7812be4409e2983675d34020e8426a3e189`.

Attribution: **geoBoundaries; National Mapping and Resource Information Authority (NAMRIA); Philippines Statistics Authority (PSA); OCHA Philippines**. License: [Creative Commons Attribution 3.0 IGO](https://creativecommons.org/licenses/by/3.0/igo/). Retain this credit and license link in redistributed data and map attribution. Upstream [license information](https://data.humdata.org/about/license) and [original source](https://data.humdata.org/dataset/philippines-administrative-levels-0-to-3) are recorded in `source-metadata.json`.

Pinned download: [geoBoundaries repository commit 41af8f1](https://github.com/wmgeolab/geoBoundaries/raw/41af8f1/releaseData/gbOpen/PHL/ADM2/geoBoundaries-PHL-ADM2_simplified.geojson). Discovery metadata: [geoBoundaries Philippines ADM2 API](https://www.geoboundaries.org/api/current/gbOpen/PHL/ADM2/). The API can change; the checked-in bytes and checksum define this version. No runtime boundary download is needed.

Import uses `ST_SetSRID(...,4326)` and `ST_Multi` without repairing, buffering, inventing, or simplifying geometry. Database constraints reject invalid or empty polygons. Version 1 tests actual `ST_Covers` on Manila, Cebu, Iloilo, Davao, Batanes, Siargao, source coastline vertices, Manila Bay and Tokyo. Coastline/boundary points are included; open sea is rejected. Tiny islands or territories omitted by the source are rejected. Disputed-territory coverage follows this frozen source only; it makes no sovereignty claim. A geographic/legal review and a newly versioned import are required to change that policy.

Labels normalize all four NCR districts to **Metro Manila**. City of Isabela maps to **Basilan**, Cotabato City to source-era **Maguindanao**; other labels remain broad source province names. This old source includes historical names and administrative arrangements (for example Compostela Valley and pre-split Maguindanao). It is a development baseline, not current administrative certification.

Version 1 configured privacy tiers use H3 resolutions as tier keys: NCR **7 urban**; explicitly listed smaller island provinces, Palawan and Mindoro **5 sparse-island**; all other provinces **6 intermediate**. The exact set lives in `seed-geo.mjs`. These conservative administrative defaults are not measured population density or a formal anonymity guarantee. Local geographic/privacy review is a launch gate. Phase 4 must implement deterministic H3/land-intersection coarsening and may escalate to a coarser tier for tiny land intersections. No coarsening algorithm or exact user coordinates are stored in this seed.

`geo_datasets.version=1` binds source attribution/checksum. `geo_admin_areas` has `(dataset_version,source_feature_id)` identity, `source_label`, `public_label`, `privacy_tier`, and GiST-indexed `geom geometry(MultiPolygon,4326)`. Repeated import verifies every feature and fails on drift instead of overwriting existing data. Seeds contain static reference data only, never fictional public thoughts.
