# Retention and deletion

These are code defaults plus operations needed to enforce them. Immediate erasure from encrypted backups is not promised. DB times are UTC; UI dates use Asia/Manila. Document any lawful exception and update public policy before changing defaults.

| Data                                  | Live rule                                                                    | Enforcement and qualification                                                                                                                                                                                                                                              |
| ------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Thought + reactions/bookmarks/reports | 30 days/720 hours from first publication; edits never extend                 | Queries exclude exact expiry immediately. Healthy separate hourly worker drains hard deletion, including hidden thoughts. No expired archive.                                                                                                                              |
| User-deleted thought                  | Immediate transactional deletion                                             | FK cascades remove dependents; quota event has its own TTL.                                                                                                                                                                                                                |
| Verified account deletion             | Current-password reauthentication, immediate session revocation/live removal | Authored thoughts/interactions cascade; nullable reporter/audit links clear. Category persists only within report lifetime.                                                                                                                                                |
| Sessions                              | Fixed seven days unless revoked earlier                                      | Reset/logout/deletion/suspension revoke; read discovery never refreshes expired rows; cleanup retires them.                                                                                                                                                                |
| Verification/reset                    | One hour, single use                                                         | Library/application claims and cleanup; restored sessions/tokens are cleared.                                                                                                                                                                                              |
| Creation quota                        | Rolling 24 hours + cleanup allowance                                         | Purged at 25 hours; no body copied.                                                                                                                                                                                                                                        |
| Abuse counters                        | Short TTL, ordinarily <=24 hours                                             | HMAC keys, no raw IP; cleanup removes expired buckets. Key rotation requires operational review.                                                                                                                                                                           |
| Minimal audit                         | 90 days                                                                      | Append-only content-free events; nullable deletion unlinking and retention cleanup.                                                                                                                                                                                        |
| Sanitized logs                        | Maximum seven days by default                                                | Production journald template requires actual dedicated-host application/rotation/timestamp verification or equivalent collector. Rehearsal uses bounded logs; exact owned containers/logs must be removed within seven days after review. No host policy was applied here. |
| Encrypted archives                    | Daily, rolling seven days                                                    | Rotate after successful backup, only tool-owned names. Override 7–365 days requires a documented exception. Real offsite mount/remote retention/alerts/key recovery/restore proof remain launch gates.                                                                     |
| Mailpit                               | Ephemeral development capture                                                | May contain verification/reset links; keep private. It is not production retention.                                                                                                                                                                                        |

Maintenance takes a whole-job advisory lock, drains bounded batches and releases on failure. Production health/freshness/cleanup lag need external monitoring; Docker does not restart solely for unhealthy status. Local proof covers immediate run/retry/restart and configured intervals, not a 24-hour soak/SLA.

Restore authenticates before import into a new isolated DB, denies runtime CONNECT, cleans expiry/sessions/tokens and remains quarantined. An old snapshot cannot know later deletions/moderation: reconcile authoritative post-snapshot state before release. Without that state, keep quarantine. See [backup/restore](backups.md) and [launch checklist](launch-checklist.md).
