# Phase 4: map and coarse-location producer contract

Implementation base: `518fda50e17f25cb225e939e0d5091dfb9a6f30a`. Phase 4 adds the primary map and coarse-location producer; publishing and thought details remain later-phase work.

## Interfaces for Phase 5

- `src/server/geo/privacy.ts` exports server-only `coarsenPhilippinesPoint(db: Pick<Pool, 'query'>, lat: number, lng: number): Promise<CoarseLocation>`. Inject the existing least-privilege runtime database/transaction. Result: `{lat,lng,label,privacyCell,privacyTier,algorithmVersion}`. Store only these coarse values in `thoughts.public_point` (longitude first), `location_label`, `privacy_cell`, `privacy_tier`, `privacy_algorithm_version`. There is no publishing implementation in this phase. Recompute on the server from the transient POST pick when publishing; do not trust client preview coordinates or metadata. Never queue, log, persist, or include the original pick in a URL.
- `LocationError.code` is `INVALID_LOCATION` or `OUTSIDE_PHILIPPINES`. Preview POST `/api/map/preview` permits exactly `{lat,lng}`, maximum 256 bytes, same APP_ORIGIN, no query string. Successful response contains only `{lat,lng,label}`; failures are generic 422/400/403/429. All responses no-store.
- `src/server/geo/pins.ts` exports `queryMapPins(db, URLSearchParams)`. GET `/api/map/pins?bbox=west,south,east,north&zoom=0..18&emotion=optional` rejects unknown/duplicate/invalid parameters. Longitude ±180, latitude ±90, south<north, west!=east. West>east splits at antimeridian. Uses Phase 1 `publishedPredicate`, so hidden/deleted/pending/expired thoughts are excluded before counting.
- `src/lib/map-contract.ts`: GeoJSON `MapPins` adds total; each point contains `kind`, thought `count`; singleton pins additionally expose `publicId`, `emotion`, broad `label`. Bulk DTO never includes body, pseudonym, author/account IDs, privacy cell, or reaction totals. Groups use an existing stored coarse point. At most 961 features including viewport edges; no count-truncating LIMIT. Accessible list pages 20 rendered markers.
- `src/components/map/map-engine.ts`: imperative MapLibre adapter returns refresh/select/focusPhilippines/center/preview. It uses clusterProperties summed thoughtCount, not point_count as the displayed number. `MapView` consumes typed catalog keys, Phase 3 preference store and dialog. Selection currently displays emotion/place only; Phase 5 can attach the detail producer by publicId at that boundary.
- Root `PublicContentGate` owns a stable abortable dynamic loader. Map engine and picker test live acknowledgment before each request and completion; disposal aborts outstanding work. SSR/RSC/metadata remain generic. No browser GPS; Permissions-Policy still denies geolocation.
- Runtime PG pool is lazy, max 2, connect/statement timeout 5s. Only DATABASE_URL reaches it. Map limits share existing atomic rate_limit_counters with global non-IP buckets: preview 120/minute, pins 600/minute. This conservative service budget is not individual visitor attribution; tune operationally before public launch.
